# PNJ/PH 已验证模型参考库

这是基础、复现、创造模式共用的案例库。接到“参考已验证模型”“把本次成功模型收录”“按已有案例改参”时使用。先读[案例索引](references/catalog.md)，仅加载相关案例；实际建模同时采用对应模式和[仿真交付规则](../comsol-pnj-ph/references/simulation-and-display.md)。

线性梯度折射率圆柱的已确认参考案例见 [GRIN-PANG-001：Pang 图 2(d)](references/pang-grin-fig2d.md)；复用这一机制时读取，其他机制先按索引选择。

同轴有限圆柱与径向偏振相向光束形成热点链的已确认案例见 [CHAIN-AO-001：Xu 图 4(a)](references/coaxial-pnj-chain-fig4.md)；此例使用二维轴对称模型、双端口同时激励和圆柱型 PML，按案例核对后复用。

直角梯形的边缘衍射 PH 已确认案例见 [EDGE-JPD-001：Xu 图 1(b)](references/edge-diffraction-trapezoid-fig1b.md)；复用时特别核对 L 为上边与高度、下边附加 L·tanα 的几何定义。

同心双椭圆核壳的已确认内核旋转扫描见 [DE-IR-001：内核30°–100°扫描](references/dual-ellipse-inner-rotation.md)；复用时核对独立旋转后的嵌套、单参数外部扫描和实际保存的15组参数解。

三维 Janus 微球与矢量 LG 涡旋光的已确认案例见 [JANUS-LG-001：Shi 图 1 基准](references/janus-lg-vortex-fig1.md)；复用时核对完整三维结构、源相位约定、BEM 变量作用域及与原文 FDTD 的迁移差异。

## 收录

用户要求以后积累所有已完成并由其验证可行的模型。相关模式完成仿真后检查用户确认状态；用户明确确认后维护索引和案例记录，无需重复索要同一确认。求解成功、场图生成或 AI 核对不能代替用户确认。尚无确认时可登记为“计算完成，待用户验证”，不得列入已验证集合。用户明确否定则标记不可用并记录原因，不继续作为可行模板推荐。

每个案例记录：稳定编号、物理机制与适用范围、COMSOL 版本、源论文/源模型、最终含解模型路径、可复用脚本及依赖、参数及单位、扫描与固定量、材料/激励/PML/网格、场图、实际计算证据、用户确认原话或可定位的会话证据及日期、验证边界和待解决问题。只登记真实存在的交付物。多参数值合并为同一案例；真正不同的几何拓扑或机制才新增案例。

实际 `.mph`、源脚本、图和验证记录保留在其 `PROJECTS_ROOT\任务文件夹`；skill 存索引、案例说明和路径，不把大型模型复制到 skill 安装目录。用户另指定存储位置时遵从。更新库前核对文件存在；路径失效则标注并找回，不静默生成替代“已验证”模型。

## 参考复用

按二维/三维、结构、光源、波长与材料选近似案例，先说明可沿用设置和必须替换部分。示例参数是特定案例条件，不是全部 PNJ/PH 的默认值。改波长、折射率、尺寸或旋转后重查介质内网格、嵌套、命名选择和 PML；原案例可行不代表新条件已验证。

新任务在 `PROJECTS_ROOT` 新建专用文件夹。以原模型为只读参考，另存副本后修改；不覆盖参考模型与证据。同一任务迭代使用该任务文件夹。执行历史 Java 脚本前检查硬编码 ROOT、输入依赖、是否清空解或删除绘图组，并改为本次副本路径。此库的查阅/收录不会自动求解或启动结果分析。

## 回写经验

将实操验证过的共性修正写入对应模式或共享参考，将结构、参数、扫描范围和特定版本行为写入案例。每次区分“通用要求”“本案例选择”“当前工具限制”，保留其他案例可用的方法。定量复现、收敛、PH 臂数等只在有相应验证证据时声称；基本场图和用户可行性确认不自动证明这些指标。
