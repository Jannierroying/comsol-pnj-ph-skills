# 基础模式：简单模型生成 PNJ 或 PH

先读并遵守[参数化扫描、计算与基本场图](../comsol-pnj-ph/references/simulation-and-display.md)：同类改参放在同一模型中，每个参数独立一个研究/参数化扫描节点，值列表用 `range(起点,步长,终值)`；实际计算后生成 `ewfd.normE^2`、Rainbow 场图。基本场图属于仿真交付，定量结果分析是独立阶段；用户暂停后处理时仍计算和生成基本场图，其余分析不自动启动。

根据目标选最小可解释模型：直线 PNJ 优先二维均匀圆柱或椭圆柱；单 PH 优先二维 Janus 材料分区圆柱或非对称梯形。二维圆截面表示沿 z 无限长的微柱，不等于三维微球。只在目标确实需要时升级结构。读 [PNJ 入门实例](references/basic-pnj.md) 或 [PH 简单结构](references/simple-ph.md)；需要完整操作次序时读 [COMSOL 操作次序](references/workflow.md)。

用户没有指定波长、尺寸、各域折射率、偏振及入射幅值时，主动给出一套具体且带单位的探索初值，并说明自行设计的依据。已指定条件优先。PNJ 可用参考实例中的 532 nm、直径 4λ、n=1.5、空气背景起步；PH 的材料分区、位置和折射率差单独设参，不把 PNJ 参数直接当作已验证的 PH 解。任何初值都需通过求解验证，不能预称成功。

先给完整可复制参数。GUI 教程按模型向导 → 全局参数 → 几何 → 定义/PML → 材料 → ewfd 激励/边界 → 网格 → Wavelength Domain → 研究参数化扫描（需要时） → 计算 → 基本场图 → 保存；定量后处理与光学收敛在独立分析阶段开展的界面次序；实际通过 MCP 或模型 API 操作时按依赖顺序执行，不强行模拟模型向导。非 GUI 建模先读[已验证的 MCP/API 流程](references/mcp-workflow.md)。波长域的 Wavelengths 输入 `lambda_ref`；物理场接口仍为 Electromagnetic Waves, Frequency Domain（ewfd）。均匀背景平面波在组件变量中用 `k_bg=2*pi*n_bg*freq/c_const`，随研究当前波长更新；沿 +x 传播的 y 偏振背景场可用 `Eamp*exp(-i*k_bg*x)`。光谱扫描保持实际几何固定，除非明确研究同比缩放。

计算后先交付 `ewfd.normE^2`、Rainbow 基本场图。以下量化仅在用户允许结果分析时开展：用总场复振幅模平方和平均能流核验外部主瓣。PNJ 报焦点、峰值、FWHM 和有定义的有效长度；PH 先确认主瓣连通且弯曲，再报轨迹、宽度、长度和角度。将内部共振、旁瓣和 PML 排除出主焦点。没有实际 COMSOL 求解时交付可执行教程，明确哪些指标仍待验证。

任务若指定论文、已有其他模型或大量特殊边界/介质，分别使用 [复现模式](../comsol-pnj-ph-reproduce/SKILL.md) 或 [复杂机制](../comsol-pnj-ph-advanced/SKILL.md)。

每次建模在 `PROJECTS_ROOT` 下新建本次专用文件夹，并把最终 `.mph`、脚本、图、数据和验证记录归集于此；仿真输出统一归集在本次任务目录。用户指定其他位置时遵从用户要求。交付前重新载入最终 `.mph`，确认研究、解和关键结果仍可读取。


参考或收录实际成功模型时使用[模型参考库](../comsol-pnj-ph-examples/SKILL.md)。仿真计算完成且用户明确确认可行后，将模型路径、条件、验证范围和确认依据加入库；尚未确认的结果单独登记待验证。案例参数仅适用于其结构；新任务另存副本。
