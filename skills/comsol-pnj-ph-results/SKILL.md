# 结果处理与验证模块

先读并遵守[参数化扫描、计算与基本场图](../comsol-pnj-ph/references/simulation-and-display.md)：同类改参放在同一模型中，每个参数独立一个研究/参数化扫描节点，值列表用 `range(起点,步长,终值)`；实际计算后生成 `ewfd.normE^2`、Rainbow 场图。基本场图属于仿真交付，定量结果分析是独立阶段；用户暂停后处理时仍计算和生成基本场图，其余分析不自动启动。

本模块不因求解成功而自动运行。用户暂停分析时停止指标提取和比较，基本场分布图由建模模式交付。用户明确恢复后，先确认输入是 `.mph`、场数据、截线数据还是截图，实际求解的波长、结构、偏振、材料、ROI 与数据类型。只得到图片时可做定性判断，不虚构精确数值。按任务读 [测量指标](references/metrics.md) 和 [收敛与故障](references/convergence.md)。

按总场及归一化 → 外部主瓣定位 → 连续分支跟踪 → 对应指标 → 网格、计算域、PML、求解器及采样敏感性 → 图和数据导出的顺序处理。`ewfd.Ex/Ey/Ez` 若已为总场，不重复加背景；E/H 模平方和平均能流分别报告。PNJ、单 PH、双 PH、多臂及表面模式采用各自适用定义。半高交点缺失、分支断裂或峰数依赖阈值时明确不确定。

交付可追踪结果：参数、单位、ROI、阈值、采样间距、插值、拟合、误差/收敛状态及原始数据位置。论文参考值、自行预测和 COMSOL 实算值分开。若只有操作指导，给用户可在结果节点执行的步骤，不宣称已测得。

每次实际分析在 `PROJECTS_ROOT` 下新建本次专用文件夹，保存派生模型、导出图、曲线、原始/处理后数据与测量记录；源文件可留在原处，不复用旧任务的输出文件夹。用户指定其他输出位置时以其要求为准。
