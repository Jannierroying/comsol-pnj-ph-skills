# 创造试验的 COMSOL 顺序

先固定一种最小候选，给真空波长、几何、背景及各材料常数、激励幅值/偏振、计算域、PML、网格和测量阈值。建立对称或空背景基线，随后只改变产生假设机制的一个变量。采用 COMSOL 6.3 的 ewfd 物理接口与 Wavelength Domain 研究；Wavelengths 输入真空波长 `lambda_ref`，组件变量 `k_bg=2*pi*n_bg*freq/c_const` 对均匀背景平面波随当前频率更新。

操作次序：模型向导 → 参数 → 几何/材料域 → 定义、函数和 PML → 材料 → 激励与边界 → 网格 → 波长域求解 → 总场和能流 → 轨迹、峰值、FWHM、长度/角度 → 网格/域/PML/采样检查 → 小范围扫描 → 导出。多机制组合先分别验证，再组合。固定几何的光谱扫描不能让几何无意跟随求解波长缩放。

先寻找是否存在连续外部主瓣，再量化；未达到目标时保留失败案例，判断是物理假设不成立、参数不合适还是数值设置未稳定。改变参数后重复必要验证。比较至少一个机制消失的对照，并保存所有实际运行条件、场数据、图和版本。仅有教程时用“预期”而非“已观察”。
