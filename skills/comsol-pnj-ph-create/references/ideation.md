# 创造研究：证据与可证伪性

对一个想法，先用一句话指定想得到的光场（直线 PNJ、单 PH、双 PH 或多臂 PH）、观察区和主指标，再列自由变量与固定约束。检索用户指定的本地文献目录或已连接的文献库中的可访问资料中相关主题，结合网络原始论文和官方 COMSOL 文档；按题名/DOI 去重，不将同一论文多个副本算多项独立证据。需新数据时核实波长、温度、材料来源和实验条件。

分析已有工作与提案的差别：几何拓扑、介质分布、激励、维度、控制机制和测量定义。理论上写出导致聚焦或弯曲的因果链，检查 Maxwell 边界条件、传播方向与偏振、尺寸参数 `D/lambda0`、相对折射率 `n_particle/n_bg`、相位差、损耗与色散。可用光程、对称性或模式分析作初筛，但不能代替全波近场求解。若利用张量、金属或强聚焦，处理相应耦合与损耗。

每个候选给出：最小结构、明确初值、为什么可能出现目标场、哪个对照会否定机制、主要风险、对照文献和期望输出。把“物理上可建模”“预计可能观察到”“已算出目标”“文献未见报道”分开。讨论点聚焦真实取舍；用户已给定的条件直接执行。
