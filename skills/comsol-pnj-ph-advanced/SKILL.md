# 复杂机制模块

先读并遵守[参数化扫描、计算与基本场图](../comsol-pnj-ph/references/simulation-and-display.md)：同类改参放在同一模型中，每个参数独立一个研究/参数化扫描节点，值列表用 `range(起点,步长,终值)`；实际计算后生成 `ewfd.normE^2`、Rainbow 场图。基本场图属于仿真交付，定量结果分析是独立阶段；用户暂停后处理时仍计算和生成基本场图，其余分析不自动启动。

仅在实际模型需要特殊介质、入射源或边界时使用。按需读 [机制](references/mechanisms.md) 与 [照明](references/illumination.md)，并与基础、复现或创造模式的目标结合。主动给具体波长、几何、材料、激励与数值初值；文献复现时原值与自行补全分开，真实材料常数注明波长和来源。

掩膜、有限光束与表面贴片有不同的物理实现；各向异性需旋转介电张量并核对场分量耦合；GRIN 函数要随粒子坐标旋转；反射结构按回传侧设置观察区；SPP 需复金属常数和表面模式激励。结构光使用完整矢量场或合适模式。不要以静态粒子旋转替代运动介质效应。

默认使用电磁波 ewfd 接口配 Wavelength Domain 研究，参数顺序遵循具体模式。三维分段均匀介质也可采用全波 BEM；记录实际接口类型及原文数值方法的迁移差异，不能将这一方法套到连续 GRIN。BEM/矢量涡旋光的已确认实现见[照明参考](references/illumination.md#三维-janus-微球与-lg-涡旋光的已确认参考)。均匀背景平面波的 `k_bg=2*pi*n_bg*freq/c_const` 在组件变量中定义，特殊模式用相应传播常数。设计机制消失的对照，检查薄层、尖角或皮肤深度网格；以总场、能流和收敛结果检验，而非仅凭云图。

实际建模时在 `PROJECTS_ROOT` 下为本次任务新建专用文件夹，保存模型、脚本、图、数据及对照；不复用旧任务文件夹。用户另指定位置时以其要求为准。若使用 COMSOL MCP，先核对其可写入的物理设置；缺少专门接口时参照[基础模式 MCP/API 实操](../comsol-pnj-ph-basic/references/mcp-workflow.md)使用模型 API 补齐，不将复杂机制强行简化成基础模型。


参考或收录实际成功模型时使用[模型参考库](../comsol-pnj-ph-examples/SKILL.md)。仿真计算完成且用户明确确认可行后，将模型路径、条件、验证范围和确认依据加入库；尚未确认的结果单独登记待验证。案例参数仅适用于其结构；新任务另存副本。
