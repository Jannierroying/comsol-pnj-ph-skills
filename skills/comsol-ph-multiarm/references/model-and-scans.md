执行时先遵守[参数化扫描、计算与基本场图](../../comsol-pnj-ph/references/simulation-and-display.md)：同一双椭圆拓扑使用一个模型的研究参数化扫描，计算后用 `ewfd.normE^2`、Rainbow 显示；下列测量/比较仅在用户恢复结果分析后开展。

### 4. 方案 C2 的专门复现模块

**仅在选择 C2 或明确要求复现《最终版.pdf》时启用本节。** 本文件及 multiarm-metrics.md中的具体波长、折射率、倾角、网格起点和测量阈值不自动适用于其他方案。

#### 4.1 结构和参数

构建二维 x-y 截面的同心双椭圆核壳微柱，沿 z 方向无限延伸。内核为较高折射率、外壳为较低折射率，背景为空气。两个椭圆的中心均为原点，长轴角度从 +x 方向逆时针计量。

论文参数及由其推导的参数如下，给出可直接录入 COMSOL 的参数名、表达式、单位和含义：

```text
lambda_ref       532[nm]
n_bg          1
n_core        1.5
n_shell       1.29
a_shell       6*lambda_ref
b_shell       a_shell/2
s_core        0.6
a_core        s_core*a_shell
b_core        a_core/2
theta_core    90[deg]
theta_shell   60[deg]
delta_theta   theta_core-theta_shell
Eamp          1[V/m]
```

在“组件 → 定义 → 变量”中另行定义 `k_bg=2*pi*n_bg*freq/c_const`，不要将其作为依赖研究变量的全局常量参数。单波长取 lambda_ref=532[nm] 时，它等于 2*pi*n_bg/lambda_ref；波长域扫描时会随当前频率自动更新。

其中 `Eamp=1[V/m]` 是便于归一化的建模约定，不能冒充论文已明确给出的实际激光功率。论文的 S 对应 `s_core=a_core/a_shell`。本任务统一使用上述有符号相对角定义。

检查推导尺寸：外椭圆长、短半轴为 3.192 μm、1.596 μm；S=0.6 时内椭圆长、短半轴为 1.9152 μm、0.9576 μm。特别区分半轴、全轴和直径，不能将 6λ 当成外椭圆全长。

初始材料采用各向同性、无损、非磁性介质，`epsilon_r=n^2`、`mu_r=1`、电导率为零。先用用户定义折射率复现论文，随后才引入真实材料的色散和损耗。BK7、PMMA 等材料名称不能替代其在指定波长的实际光学常数，n=1.29 的外壳也不能直接设为普通 PMMA。

#### 4.2 偏振、物理场和入射波

C2 复现模型必须与论文的入射波一致：沿 +x 传播、电场沿 y 方向线偏振。

采用 Wave Optics → Electromagnetic Waves, Frequency Domain（ewfd）物理场接口和 Wavelength Domain（波长域）研究，求解全波麦克斯韦方程。在研究的 Wavelengths 栏填写 lambda_ref，波长单位选择 nm。优先采用 Scattered field 公式和背景平面波。

COMSOL 的时间因子采用 exp(+iωt)，因此背景场的分量表达式为：

```text
Ebg_x = 0
Ebg_y = Eamp*exp(-i*k_bg*x)
Ebg_z = 0
```

说明如何在 COMSOL 6.3 的背景平面波或 User defined 设置中实现这些分量。背景波数始终按 n_bg 定义，不应随粒子局部折射率改变；介质对比产生散射源项。

二维模型优先选择 In-plane vector，求解 Ex、Ey，并设置面外波数为零；如使用 Three-component vector，应说明在当前各向同性、z 不变条件下的等价性。不能用只求解 Ez 的 Out-of-plane vector 来冒充本文的 y 偏振。不同论文中的 TE/TM 命名可能不同，始终用传播方向和非零场分量说明实际设置。

若研究偏振影响，可在论文偏振的基准案例通过后另建 Ez 对照，并明确这属于新增研究条件。

#### 4.3 几何、域选择和 PML

按模型向导、参数、几何、定义/PML、材料、物理场、网格、波长域、求解、后处理、收敛扫描与导出的顺序逐项展开 C2 模型，把本节的几何与 PML 设置插入对应步骤。每项说明模型树节点、中文和英文名称、录入表达式、域或边界选择，以及完成后的检查方法。

几何必须形成互不重叠的内核、外壳、背景空气和 PML 域。说明使用差集、分割或保留内部边界的 Form Union 如何完成该结构，并用命名选择管理材料域和边界。

独立旋转后必须验证内椭圆仍完全位于外椭圆内，检查最小壳厚；S<1 本身不足以保证任意相对角度下嵌套成立。对非法组合跳过并记录原因，不能将相交椭圆自动裁切后继续称为原论文的同心核壳结构。薄壳区域应单独检查网格解析度。

论文未公开完整计算域和 PML 尺寸。可提出一个明确标为“补全建模的初始建议”的空气域，例如 x∈[-10λ₀,25λ₀]、y∈[-10λ₀,10λ₀]，外围再设置约一个背景波长厚的 Cartesian PML。需要验证时通过研究参数化扫描改变空气域、PML 厚度及网格参数；光学指标比较在独立分析阶段开展；观察区域不能进入 PML。

说明 PML 在 Definitions 中的域设置、材料、拉伸类型和外边界处理。若使用 polynomial stretching，可从穿过 PML 厚度的至少 8 个网格单元起步，最终以吸收和收敛效果为准。

内核-外壳、外壳-空气和物理域-PML 交界不应误施加 PEC。检查默认 PEC 节点的选择，仅按所用 PML 配置处理最外边界。背景场激励不能再叠加重复的端口或入射边界源。

#### 4.4 最小复现案例和分阶段扫描

先求解几个代表案例、确认几何和数值设置，再开展扫描：

1. 空背景校验：所有域折射率设为 n_bg，检查相对散射场接近零、归一化总场接近 1、平均能流指向 +x。
2. 基准 PNJ：S=0.6，theta_core=90°、theta_shell=90°。
3. 三臂 PH：S=0.6，theta_core=90°、theta_shell=60°；再比较 theta_core=60°、theta_shell=60°。
4. 外椭圆调控的四臂 PH 候选：S=0.6，theta_core=60°、theta_shell=70°。
5. 内椭圆调控的四臂 PH 候选：S=0.6，theta_core=30°、theta_shell=60°。

以下现象是论文的复现目标，不能在未求解时当成已经获得的结果，也不能作为预设分类标签强行覆盖模拟结果：

- S=0.5、theta_core=theta_shell=60° 时，论文报告两个有效峰约位于 x=4.1 μm 和 5.0 μm，归一化强度约为 8.19 和 5.31。x≈6.9 μm 处约 4.07 的峰因低于 8.19/2=4.095 被排除，这种接近阈值的情况尤其需要数值敏感性检查。
- S=0.6、theta_core=90°、theta_shell=90° 时，论文报告 PNJ 峰值约 12.62、FWHM 约 0.74λ₀；theta_core=60°、theta_shell=90° 时对应峰值约 10.93。
- theta_core 固定为 90° 或 60°、theta_shell 在论文考察的 45°-90°范围内变化时，主聚焦区报告的 FWHM 约为 0.7λ₀-0.9λ₀。这个范围不适用于任意角度组合。
- theta_shell=60°、theta_core≈65°-95° 时，论文报告形貌和聚焦性能较稳定，拐点 FWHM 的变化小于 0.01λ₀。

分阶段复现（在同一 `.mph` 的研究 → 参数化扫描中设置；不要每角度另存模型）：

- 尺寸扫描：theta_core=theta_shell=60°，S=0.2、0.5、0.6、0.7。比较有无内核的结果。图 2 的单椭圆对照中哪些尺寸和折射率保持不变，应先依据原文核对；如信息不完整，明确说明假设。另加固定外形、令 n_core=n_shell 的严格去除折射率界面对照。
- 外椭圆扫描：S=0.6，分别固定 theta_core=90°、60°，扫描 theta_shell=45°-90°。5°作为自行提出的初始步长；在 65°-70°及形态转换附近按需要加密。
- 内椭圆扫描：S=0.6，固定 theta_shell=60°，扫描 theta_core=30°-100°；在焦点分裂和 65°-95°稳定区间加密。
- 最后才研究折射率、环境折射率、入射角和波长。做光谱扫描时保持实际几何尺寸固定；按 λ 缩放所有几何参数属于另外一种相似性研究，不能混用。

#### 4.5 网格和收敛

论文将微粒内部及散射区最大网格尺寸限制在 λ₀/20 以下，即约 26.6 nm。以此作为复现起点，同时核对介质内最短波长 λ₀/n_max、单元阶次、界面曲率和局部壳厚。

在内核、薄壳、出射界面、聚焦区和次级焦点分裂区设置可追踪的局部加密；PML 使用适合其几何的映射网格。固定单元阶次和几何离散规则，需要定量验证且用户允许分析时，至少用三档网格比较峰值、焦点位置、FWHM、有效峰数、臂长和弯曲角。

分别检查网格、空气域、PML、求解器容差和后处理采样的敏感性。软件完成求解、云图平滑或多个参数算例形状相似，都不能替代收敛验证。

需要核验“FWHM 变化小于 0.01λ₀”时，注意 0.01λ₀=5.32 nm，FWHM 测量与求解的不确定度应明显小于该变化尺度。纵向 100 nm 的切片步长、横向采样步长和有限元网格尺寸是不同参数，不能互相替代。
