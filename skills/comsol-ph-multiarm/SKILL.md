# 《最终版.pdf》同心双椭圆多臂专例

先读并遵守[参数化扫描、计算与基本场图](../comsol-pnj-ph/references/simulation-and-display.md)：同类改参放在同一模型中，每个参数独立一个研究/参数化扫描节点，值列表用 `range(起点,步长,终值)`；实际计算后生成 `ewfd.normE^2`、Rainbow 场图。基本场图属于仿真交付，定量结果分析是独立阶段；用户暂停后处理时仍计算和生成基本场图，其余分析不自动启动。

本 skill 是 [复现模式](../comsol-pnj-ph-reproduce/SKILL.md)的专例。来源是 最终版.pdf（原文需由用户提供）。建模前读 [原文模型与扫描](references/model-and-scans.md)，分析时读 [多臂指标](references/multiarm-metrics.md)。图文的角度定义有一处不一致；按图 3—7 和后文用 `theta_core` 为内椭圆角、`theta_shell` 为外椭圆角。

原始基准是二维同心核壳，`lambda_ref=532[nm]`、`n_bg=1`、`n_core=1.5`、`n_shell=1.29`、外椭圆长短半轴分别为 `6*lambda_ref` 和 `3*lambda_ref`。入射沿 +x，电场沿 y。用 ewfd 配 Wavelength Domain，组件变量 `k_bg=2*pi*n_bg*freq/c_const`。内外椭圆独立旋转，每组验证完全嵌套和最小壳厚；论文没有给出的域/PML 设置只能标成补全值。

先运行原文基准和代表性 PNJ、三臂、四臂案例，再做用户指定改参。以下多臂判断只在用户允许结果分析时开展。多臂判断先确认同一条连通弯曲 PH，再按原文中线强度局部峰定义有效 IP；不能把峰数直接当成 PH 条数或在直线 PNJ 上套多臂规则。100 nm 切片和阈值用于原文复现，同时做采样敏感性检查。论文数值是目标而非未求解模型的结果。需要其他软件模型迁移时同时遵守复现模式的来源映射。

每次实际复现在 `PROJECTS_ROOT` 下新建专用文件夹，保存基准、三臂、四臂及改参 `.mph`、脚本、图、数据和原文对照；不复用旧任务文件夹。用户另指定输出位置时以其要求为准。非 GUI 建模可参考[基础模式 MCP/API 实操](../comsol-pnj-ph-basic/references/mcp-workflow.md)，但本专例的几何与测量定义优先。


参考已有可行模型时按需读取[模型参考库](../comsol-pnj-ph-examples/SKILL.md)。仿真完成后检查用户确认状态：有明确确认则收录案例及确认依据；只有计算成功时登记待验证，不能代替用户确认。复用时另存新任务副本，不覆盖参考模型；该案例的参数与验证范围不自动推广到其他结构。
